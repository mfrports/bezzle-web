Menu shortcuts work whenever Bezzle's window is in front. The tool keys and the canvas keys work while the canvas has the keyboard: click the canvas, or press {{Esc}} in a field, to give it back. Many menu items have no shortcut and are listed anyway, so you can find them; each is explained on the page linked beside its table.

## Tools {#tools}

Press a tool's key on its own (with {{⇧}} or Caps Lock it works too). In Prototype and Inspect, where nothing is drawn, the tool keys do nothing.

| Key | Tool |
|---|---|
| {{V}} | {Select} |
| {{A}} | {Artboard} |
| {{R}} | {Rectangle} |
| {{E}} | {Ellipse} |
| {{L}} | {Line} |
| {{P}} | {Pen} |
| {{K}} | {Knife} |
| {{T}} | {Text} |
| {{N}} | {Note} |
| {{Space}} held | The hand: drag to move around, with any tool |
| {{Esc}} | Puts the tool down and picks {Select} again |

## On the canvas {#canvas}

See [The canvas](/docs/canvas.html).

| Key | What it does |
|---|---|
| {{←}} {{→}} {{↑}} {{↓}} | Moves what is selected by 1 point |
| {{⇧}} with an arrow | Moves it by 10 points |
| {{⌫}} or {{⌦}} | Deletes what is selected |
| {{Return}} | On one selected text, starts typing; on a path, shows its points; on a layer filled with a picture, places the picture; on a mask, picks what it holds |
| {{Esc}} | Cancels a drag going on; else puts the tool down; else picks the group or artboard the selected layer lies in; else lets go of the selection. An open note in the margin is put away first |
| {{Page Up}}, {{Page Down}} | Turns a deck to the post before or after |

## Modifiers while you drag {#modifiers}

### With the Select tool {#select-modifiers}

| Gesture | {{⇧}} | {{⌥}} | {{⌘}} |
|---|---|---|---|
| Click a layer, or an artboard's name | Adds it to the selection, or takes it out | | |
| Drag a box | Adds to the selection | | |
| Move | Straight across or down | Moves a copy (hold it as you press) | Nothing catches |
| Resize by a handle | Keeps the proportions | From the middle; nothing catches | Nothing catches |
| Turn, just outside a corner | Steps of 15° | | |
| Drag a line's end | Steps of 45° | | Nothing catches |
| Drag a corner's dot (rectangle or path) | | Rounds only that corner | |
| Drag a shadow | Straight across or down | | |
| Drag a shape's edge | With {{⌥}}, keeps the copy's corners round | Pulls a copy of the outline out or in | |
| Turn in depth, just outside a side | Turns one way only, in steps of 15° | | |
| Drag a turned layer's knob | Steps of 15° | Brings it nearer or pushes it away | |
| Drag a repeat grid's gaps | Across and down change together | | |
| Turn a repeat grid | Steps of 15° | | |
| Swing a text's bead | | | Held during the swing, leaves the catches (straight, half circle, ring) |
| Drag a guide | Whole tens from the nearer edge | Drags a copy (by its line) | Nothing catches |

Most of these change at once when you press or let go of the key during the drag. Double-click a turned layer's knob to lay it flat again. See [Corners](/docs/shapes.html#corner-dots), [Outset and inset](/docs/shapes.html#outset), [Moving a shadow](/docs/looks.html#shadow-on-canvas), [Turning in depth](/docs/looks.html#depth-on-canvas), [Spacing the cells](/docs/layout.html#grid-gaps), [Bending text](/docs/text.html#bending) and [Guides](/docs/canvas.html#guides).

### Drawing {#drawing-modifiers}

| Tool | {{⇧}} | {{⌥}} | {{⌘}} |
|---|---|---|---|
| {Artboard}, {Rectangle}, {Ellipse}, a {Text} box | Square, or a circle | Draws out from the middle | Nothing catches |

### The Pen {#pen}

See [The pen](/docs/shapes.html#pen).

| To | Do this |
|---|---|
| Put down a corner | Click |
| Pull a curve out of the point | Drag as you click |
| Keep to steps of 45° from the last point | {{⇧}} |
| Leave the handle coming in as it was, for a point that bends | {{⌥}} while you pull the curve |
| Place the point freely, catching on nothing | {{⌘}} |
| Close the path | Click its first point |
| Leave the last point straight | Click the last point again |
| End an open path | {{Return}} or {{Esc}} |
| Take the newest point back | {{⌫}} |

### Editing points {#points}

See [Editing points](/docs/shapes.html#editing-points).

| To | Do this |
|---|---|
| Start, or stop | Double-click a path or shape; {{Return}} on a path; {{Return}} or {{Esc}} to stop |
| Pick a point | Click it; {{⇧}}-click to add or take away |
| Pick several | Drag round them; with {{⇧}}, add to those picked |
| Pick every point | {{⌘A}} |
| Move picked points | Drag; {{⇧}} keeps straight, {{⌘}} catches on nothing |
| Move them a little | Arrow keys, 1 point; with {{⇧}}, 10 |
| Move one handle alone | {{⌥}} as you drag it; {{⇧}} keeps it to 45° |
| Make a point smooth or a corner | Double-click it |
| Add a point | Click the outline |
| Delete picked points | {{⌫}} |

### The Knife {#knife}

See [The Knife](/docs/shapes.html#knife).

| To | Do this |
|---|---|
| Cut along the way the pointer goes | Drag across the shapes |
| Cut in a straight line | {{⇧}} as you drag |
| Put a cut line down point by point | Click, click; drag as you click to pull a curve; {{⇧}} keeps to 45° |
| Make the cut | {{Return}}, a double-click, or a click on the first point |
| Take the newest point back | {{⌫}} |
| Let the line go | {{Esc}} |

## Typing text {#typing}

See [Typing](/docs/text.html#typing) and [Lists](/docs/text.html#lists).

| Key | What it does |
|---|---|
| {{Esc}} | Stops typing. If the Text tool is in hand, it stays there, and a second {{Esc}} puts it down |
| {{⌘Z}} | Takes back what you just typed |
| {{Return}} on an empty item of a list | Ends the list |
| {{⌫}} at the start of an item of a list | Ends the list there |
| {{Tab}}, {{⇧Tab}} in a deck's post | Goes on to the same text in the next post, or back to the one before |
| {{⌘F}} with letters picked out | Finds those letters |

The {Format} menu's shortcuts work while you type, on the letters picked out, or on what you type next.

## Number fields and cards {#fields}

See [Number fields](/docs/canvas.html#number-fields).

| To | Do this |
|---|---|
| Step the number | {{↑}} {{↓}}; with {{⇧}}, ten times as far |
| Drag finely | {{⌥}} while you drag across the field |
| Drag in whole tens | {{⇧}} while you drag |
| Put a drag back | {{Esc}} during it |
| Keep what you typed | {{Return}}, or click elsewhere |
| Leave the number as it was | {{Esc}} while typing |

Names typed in place (a tab, an artboard, a layer in the list, a card on home) keep what you typed with {{Return}} or a click elsewhere, and stay as they were with {{Esc}}. An artboard's name also keeps it with {{Tab}}.

## Bezzle's menus {#menus}

The zoom menu, the menus in the inspector and the right-click menus all take the same keys.

| Key | What it does |
|---|---|
| {{↑}} {{↓}} | Moves through the menu |
| {{Return}} | Chooses |
| {{Esc}} | Closes it; in a menu you type into, such as the font menu, first clears what you typed |
| Typing | Narrows a menu you can type into |
| {{⌫}} | Takes back a letter; with {{⌥}} or {{⌘}}, all of them |
| {{⌘V}} | Pastes into what you are typing |
| {{⌫}} in the fill menu, on a gradient | Takes the chosen color off the gradient, which keeps at least two |
