# Bezzle

The website of [Bezzle](https://mfrports.github.io/bezzle-web/), the free design app for Mac: home page, download, what's new, support and privacy policy in English, German, French and Italian, and the update feed of the copy from this website (`updates/appcast.xml`). The downloads are this repository's [releases](https://github.com/mfrports/bezzle-web/releases).

To report a problem or suggest something, [open an issue](https://github.com/mfrports/bezzle-web/issues/new).
